# Sun Petal Kingdom

A Godot 4 adventure game set in Ocala, Florida.

## Development Stack
- Engine: Godot 4.2.2 (stable)
- Editor: Cursor + godot-tools extension
- Language: GDScript

## Project Structure
```
scenes/       — .tscn scene files
scripts/      — .gd GDScript files
assets/
  textures/   — sprites, tilesets, images
  audio/      — music and SFX
  fonts/      — font files
ui/           — UI scenes and themes
addons/       — Godot plugins
```
